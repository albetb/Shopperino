# Languages

> Which languages a character knows, how to gain more, class-tied languages, and literacy.

## Automatic languages

- Granted free by the character's race at creation. Cannot be unlearned.
- **Common** is the automatic language of most "civilized" races and is also widely understood by every other PC race.
- Other races contribute their racial language as the second automatic (e.g. Dwarven for dwarves, Elven for elves).

## Bonus languages

- Each race has a **bonus-language list** of languages typically learned (neighbor races, enemies, trade partners).
- A character chooses **one bonus language per +1 of Intelligence modifier** at character creation, drawn from the race's bonus list (or from the Speak Language pool — see below).
- Bonus languages chosen at creation are free.

## Speak Language skill

- The **Speak Language** skill is exception-shaped: each rank = fluency in one additional language. No check is rolled and no ability modifier applies.
- Use Speak Language to learn languages outside the race's bonus list.
- A new language costs 1 SP per language (subject to class/cross-class rules; see [skills.md](skills.md)).

## Class-tied languages

A few classes unlock languages independently of race:

- **Cleric** — may add **Abyssal, Celestial, or Infernal** to bonus languages.
- **Druid** — gains **Druidic** automatically as an extra language. *Druidic is a class secret*: a druid who deliberately teaches it to a non-druid loses all druid class features. Druidic is in addition to the standard automatic/bonus languages.
- **Wizard** — may add **Draconic** to bonus languages.

## Literacy

- **Default rule**: a character can read and write every language they speak.
- **Exception — Barbarian**: a 1st-level barbarian is illiterate (in *all* known languages). They can become literate by spending **2 skill points** as a one-time purchase, which grants literacy in every language currently known.
- A character who multiclasses *into* barbarian after another class retains the literacy they already had.
- A character whose 1st level is barbarian and then multiclasses into another class remains illiterate until the 2-SP literacy cost is paid.

## Edge cases & exceptions

- A character with Int mod ≤ 0 gets no bonus languages at creation; they still get racial automatic languages.
- Druidic does not count toward the barbarian-style illiteracy exception — druids are literate in their other languages and in Druidic.
- A character may select the same language only once; spending another rank/bonus on a language already known is wasted.
